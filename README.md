What it does
- Turns recipes into editable 3D models. A recipe is a small TypeScript program. You can change its parameters, colours and presets, save designs, and rebuild the model reproducibly.
（把「配方」变成可编辑的 3D 模型：配方是一小段 TypeScript 程序，可改参数、改颜色、存设计、可复现地重新构建。）
- Is built for AI agents. An agent toolkit lives in integrations/agents, plus a local MCP server and agent-readable docs: a coding-agent brief, an authoring guide and a *.controls.json control manifest for each model.
（为 AI 编程助手而生：内置 agent 工具包、本地 MCP 服务和配套文档。）
- Supports several export formats. GLB is the source of truth. OBJ (zipped with MTL), binary FBX and USDZ are also available, along with saved-design JSON, procedural/snapshot .mjs modules and editable source ZIPs. See export formats.
（支持多种导出格式：GLB 为主，另有 OBJ、FBX、USDZ、设计 JSON、.mjs 模块和可编辑源码包。）
- Works in game engines. A Unity editor package lives in integrations/unity. Godot and other engines import the GLB/OBJ/FBX output.
（可直接进游戏引擎：Unity 有编辑器扩展包，Godot 等引擎导入 GLB/OBJ/FBX。）
Quick start
npm ci --ignore-scripts --no-audit --no-fund
npm run dev        # local toolkit / editor
npm test           # unit tests
Requires Node.js 22.x. Open the local URL printed by Vite.
For a production build and local preview:
npm run typecheck
node_modules/.bin/vite build
node_modules/.bin/vite preview --host 127.0.0.1 --port 4173 --strictPort
Ask your agent for an asset
Give your coding agent the coding-agent brief and describe the desired model, dimensions, style and target when known. It first selects and customizes an existing recipe. If the request needs different construction, it extends or authors a recipe using the authoring guide.
The agent owns setup, implementation, checks, renders, independent visual review, repairs and target import/use verification, and delivers the asset, saved design, editable source and reproduction inputs. You do not need to run commands yourself.
The current catalog contains fourteen model families with editable construction, colors, saved designs and GLB export — work-lantern, cottage, tree, fence, crate, boulder, bench, planter, treasure-chest, wheelbarrow, stone-well, conifer and more.
CLI export
npm run export -- --family fence --out exports/fence.glb
npm run export -- --config path/to/model.design.json --out exports/model.glb
Use local MCP
The stateless stdio tools are search_assets, get_asset, build_variant and export_asset. Configure your MCP client to run:
node --import tsx src/mcp/stdio.ts --output-dir /absolute/export/directory
The default output directory is exports/. Restart the process after source or dependency changes.
